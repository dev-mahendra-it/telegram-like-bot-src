### ⚡ **A Telegram Bot that sends likes to Free Fire players using the Like Sender API.**

It calls the **Free Fire Like API** with **region** and **UID**, shows an **animated loading bar** while processing, and returns beautiful **formatted player stats** — nickname, level, likes before/after, likes given, and daily usage progress.

</div>

---

## 🚀 Features

<table>
<tr>
<td>

- ✅ Send likes via simple command: `/like <region> <uid>`
- 🎬 **Animated loading bar** with progress frames
- 🎨 Beautiful **HTML-formatted** output with boxes and emojis
- 📊 Shows **likes before**, **likes after**, and **likes given**
- 📅 **Daily limit progress bar** (200 likes/day)
- 🔁 **Re-Like button** — instant re-send without typing again
- 📖 Help and Credits inline buttons
- 🌍 **Multi-region support** (BD, IN, PK, SG, ID, MY, TH, VN, BR, US)
- 🛡️ **UID validation** and **error handling**
- ⚡ Fully **async** with `aiohttp`

</td>
</tr>
</table>
